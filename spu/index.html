Songs from Parallel Universes

Songs from Parallel Universes is a personal project. It is a self-hosted tool that produces music videos and uploads them to its owner's own YouTube channel, @SongsfromParallelUniverses.

The tool is used only by its owner. It is not offered to the public, and no one else signs in to it.

It uses YouTube API Services to upload videos and set their visibility.

Privacy Policy

Effective September 15, 2026

Songs from Parallel Universes ("the app") is a personal, self-hosted tool used only by its owner to upload videos to the owner's own YouTube channel. It is not offered to the public.

What the app accesses

When the owner signs in with Google, the app receives permission to manage the owner's YouTube account. It uses that permission only to upload videos the owner has produced and to change those videos' visibility (private, unlisted or public).

What the app stores

The app stores one OAuth refresh token on the owner's private server so uploads can run without signing in each time. It does not store Google account profile data, channel analytics, comments, subscriber information or any data about other people.

Sharing

No data is sold, shared or transferred to anyone. The app has no analytics, no advertising and no cookies. The only data sent to Google is the video, title, description and visibility setting needed for the upload.

YouTube API Services

The app uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google account's third-party connections page. Revoking access makes the stored token useless; the owner can also delete it from the server.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
